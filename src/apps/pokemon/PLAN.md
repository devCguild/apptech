# 포켓몬 실루엣 퀴즈 기획

## 개요

포켓몬 실루엣 퀴즈는 팀 앱테크 서비스에 들어갈 퀴즈 기능이다. 화면에 포켓몬 실루엣을 보여 주고, 사용자가 이름을 입력해 맞히면 포인트를 준다. 포켓몬 데이터와 이미지는 [PokeAPI](https://pokeapi.co/)에서 가져온다.

팀 서비스는 팀원마다 외부 API로 퀴즈나 보상 기능을 하나씩 만들고, 이를 한 앱으로 합쳐 제공한다. 프론트엔드는 React + Vite로 만들고 UI는 원티드 디자인 시스템 Montage(`@montage-ui/core`)를 쓴다. 팀 앱은 앱인토스처럼 공통 입구(홈·전체 앱·내 기록)에서 미니앱으로 들어가는 구조이고, 이 퀴즈는 미니앱 `pokemon`으로 `src/apps/pokemon/`에 둔다.

## 사용 흐름

1. 퀴즈 화면에 들어오면 1~151번 포켓몬 중 한 마리의 실루엣을 보여 준다.
2. 사용자가 이름을 입력하고 제출한다. 엔터로도 제출된다.
3. 정답이면 컬러 일러스트와 이름을 보여 주고 10 P를 준다. 오답이면 입력칸이 흔들리고 "땡!"을 보여 준 뒤 다시 입력받는다.
4. "모르겠어요"를 누르면 정답을 공개하고 포인트는 주지 않는다.
5. 정답이 공개되면 "다음 문제" 버튼에 포커스가 가서 엔터로 넘길 수 있다. 다음 문제가 뜨면 입력칸에 포커스가 간다. 처음 페이지를 열 때는 포커스를 옮기지 않는다.

입력칸 위의 "힌트 보기"를 누르면 첫 글자와 글자 수를 보여 준다(예: 피○○). 힌트를 봐도 포인트는 같다. 이름이 한 글자인 포켓몬은 첫 글자가 곧 정답이라 힌트 버튼을 보여 주지 않는다.

## 데이터 출처

PokeAPI의 두 엔드포인트를 쓴다. 주소는 레포 규칙대로 `src/api.js`의 `API`에 둔다.

| 엔드포인트 | `API` 키 | 쓰는 값 |
|---|---|---|
| `GET /api/v2/pokemon/{id}` | `pokemon` | 공식 일러스트 URL (`sprites.other.official-artwork.front_default`) |
| `GET /api/v2/pokemon-species/{id}` | `pokemonSpecies` | 언어별 이름 (`names`의 `ko`, `en`) |

## 실루엣과 정답 공개

이미지는 원본 그대로 받고 CSS로 실루엣을 만든다. `.pq-pokemon`에 `filter: brightness(0)`을 걸면 검은 윤곽만 남고, 정답이 공개되면 이 필터를 뺀다. 흰 외곽선은 번짐 없는 `drop-shadow` 네 개로 그린다.

이미지 URL에는 포켓몬 번호만 들어 있고 이름은 없다. 정답 공개 전에는 `alt`에도 이름을 넣지 않는다.

## 정답 판정

`quiz.js`의 `isCorrect`가 입력값과 이름의 공백을 모두 지우고 소문자로 바꿔 비교한다. 정답 언어를 정하기 전까지는 한국어와 영어 이름을 모두 정답으로 받는다.

## 구조

레포 `CLAUDE.md`의 앱 구조 규칙대로 미니앱 하나를 `src/apps/<앱id>/` 폴더 하나에 둔다. 시작 파일은 `index.jsx`의 기본 내보내기다.

```
src/apps/pokemon/
├── index.jsx              # PokemonQuiz (기본 내보내기): 지금 문제·공개 여부·포인트, 다음 문제 미리 받기
│                          # QuizStage: 실루엣 무대 (memo)
│                          # QuizForm: 입력값·오답·힌트·제출
├── PokemonQuiz.css        # 퀴즈 전용 스타일, 클래스는 모두 pq- 로 시작
├── pokeapi.js             # PokeAPI 호출, 캐시, 미리 받기
├── quiz.js                # 문제 뽑기, 정답 판정, 힌트
├── storage.js             # 포인트: lib/points.js 로 적립
├── assets/                # 홈·전체 앱 그림 (icon.png, card.png)
└── PLAN.md
```

폴더 밖 공용 파일 두 곳에도 이 미니앱 내용이 있다.

| 파일 | 내용 |
|---|---|
| `src/api.js` | PokeAPI 주소 (`pokemon`, `pokemonSpecies`) |
| `src/apps/registry.js` | `MINI_APPS`의 `pokemon` 항목 |

## 상태와 렌더링

상태는 바뀌는 범위가 좁은 컴포넌트에 둔다.

| 상태 | 위치 | 이유 |
|---|---|---|
| 지금 문제, 다음 문제 번호, 공개 여부, 포인트 | `PokemonQuiz` | 무대와 입력 영역이 같이 쓴다 |
| 입력값, 오답 표시, 흔들림, 힌트 열림 | `QuizForm` | 글자를 칠 때 무대를 다시 그리지 않게 |

`QuizStage`는 `memo`로 감싸서 문제나 공개 여부가 바뀔 때만 다시 그린다. 번쩍임은 공개될 때만 붙는 `.pq-flash` 레이어로 재생하고, `<img>` 요소는 문제가 바뀌어도 새로 만들지 않고 `src`만 바꾼다. `QuizForm`은 문제 번호를 `key`로 받아서 문제가 바뀌면 입력값과 힌트가 초기화된다.

## 불러오기와 캐시

`pokeapi.js`의 `fetchPokemon`은 요청을 번호별로 보관해서 같은 포켓몬을 다시 부르지 않는다. 실패한 요청은 지워서 "다시 시도"로 다시 부를 수 있다.

지금 문제가 보이면 `preloadPokemon`으로 다음 문제의 데이터를 받고 이미지를 미리 디코딩한다. "다음 문제"를 누를 때 `peekPokemon`으로 미리 받아 둔 데이터를 바로 꺼내서 "불러오는 중" 화면 없이 넘어간다. 미리 받기가 실패하면 넘길 때 다시 부르고, 그래도 실패하면 안내와 "다시 시도" 버튼을 보여 준다.

## 포인트 저장

포인트를 읽고 쓰는 코드는 `storage.js` 한 곳에 모은다. 퀴즈 코드는 `getPoints()`, `addPoints(n)`만 부르고 저장 위치를 모른다.

`storage.js`는 팀 공통 `src/lib/points.js`의 `addPoints("pokemon", 10, "포켓몬 실루엣 퀴즈 정답")`으로 적립 기록을 쌓는다. 기록은 localStorage `daily3_points`에 저장되고, 홈과 내 기록 화면의 포인트가 같은 기록을 읽는다. 퀴즈 화면 위에는 홈과 같은 전체 잔액을 "내 포인트"로 보여 준다. 적립 기록에는 `appId`가 남아서 내 기록 화면에서는 어느 앱에서 받았는지 구분된다.

## 디자인

화면은 실루엣이 놓이는 무대 영역과 그 바깥으로 나눈다. 무대 바깥은 Montage를 따르고, 무대 영역에서만 애니메이션 막간 퀴즈 분위기를 낸다. 원작의 공식 로고, 효과음, 캡처 이미지는 쓰지 않고 색과 구도, 연출로만 분위기를 따라간다.

바탕은 미니앱 틀(`.mini-app`)의 흰색을 그대로 쓴다. 틀이 그리는 위 헤더도 흰색이라, 퀴즈 바탕을 다른 색으로 바꾸면 헤더 아래에 경계가 생긴다.

무대 바깥은 Montage 컴포넌트와 토큰만 쓴다.

| 요소 | Montage |
|---|---|
| 글자 | `Typography`. 내 포인트는 한 줄에 `label1` 이름과 `label1` 굵은 브랜드색 숫자, 작은 안내는 홈과 같은 `caption1`, 무대 문구는 `title2` |
| 제출, 모르겠어요, 다음 문제, 다시 시도 | `Button` |
| 힌트 보기 | `TextButton` + `@montage-ui/icon`의 `IconBulb` |
| 이름 입력 | `TextField` |
| 정답·공개·불러오기 실패 안내 | `SectionMessage` |
| 글자색 | `semantic.foreground.*` 토큰 |
| 간격, 모서리 | `--spacing-*`, `--radius-*` CSS 변수 |

무대 영역은 그라데이션 없이 솔리드한 느낌으로 만든다. 그림자, 블러, 반투명도 쓰지 않는다.

| 요소 | 표현 |
|---|---|
| 배경 | 진한 파랑(`#2a4b9b`)과 밝은 파랑(`#3b6fd1`)이 경계가 딱 떨어지게 번갈아 나오는 방사형 줄무늬 |
| 실루엣 | 검정 단색, 흰색 단색 외곽선 |
| 정답 공개 | 흰 화면이 한 번 번쩍한 뒤 바로 컬러 일러스트로 바뀐다 |
| 문구 | "이건 누구일까?", "정답은 ○○!". 노랑(`#ffcb05`) 글자에 두꺼운 파랑 외곽선 |

`prefers-reduced-motion`이 켜져 있으면 번쩍임과 흔들림을 끈다.

화면 맨 아래에 비공식 팬 퀴즈라는 안내와 권리자, 데이터 출처(PokeAPI)를 적고, 포인트가 연습용이라 현금이나 실제 보상으로 바꿀 수 없다는 안내도 적는다. GitHub Pages로 누구나 볼 수 있게 공개되기 때문이다.

## 팀 앱 통합

`src/apps/registry.js`의 `MINI_APPS`에 등록해서 홈, 전체 앱, 내 기록에 나온다. 주소는 `#/apps/pokemon`이고, 위의 뒤로 가기·앱 이름 줄은 공통 틀(`MiniAppPage`)이 그린다.

| 항목 | 값 |
|---|---|
| `id` | `pokemon` |
| `name` | 포켓몬 퀴즈 |
| `category`, `tone` | `quiz`, `blue` |
| `summary` | 실루엣 보고 맞히기 |
| `catalog` | 실루엣을 보고 / 포켓몬을 맞혀요 |
| `cta` | 맞히러 가기 |
| `icon`, `banner`, `card` | `assets/icon.png`, `assets/card.png`. 입구의 다른 그림처럼 연파랑 바탕의 말랑한 3D 느낌으로 그리고, 실루엣은 특정 포켓몬이 아닌 생물 모양으로 그린다 |

## 정하지 않은 것

- 문제당 포인트. 지금은 10 P(`POINTS_PER_QUIZ`)다
- 정답 언어 (지금은 한국어·영어 모두 정답)
- 출제 범위 (지금은 1세대, `MAX_POKEMON_ID = 151`)
